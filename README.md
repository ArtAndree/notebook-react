# Между строк — блокнот на React

Учебный проект на **React + TypeScript + Vite + Emotion**.

## Задание

1. Блокнот с textarea и меню записей слева. Создание, выбор и редактирование записей.
2. Удаление записей.
3. Поиск записей.

Все три пункта реализованы. Дополнительно: заголовки, автоматическое сохранение в localStorage, дата изменения, счётчик слов и символов, адаптивная вёрстка.

## Запуск

Установите Node.js 22.12+ (рекомендуется ветка 22 LTS) и откройте терминал в папке с package.json.

```bash
npm install
npm run dev
```

В PowerShell, если блокируется npm.ps1:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес из терминала, обычно http://localhost:5173.

```bash
npm run typecheck
npm run build
npm run preview
```

Сборка создаёт папку dist. Исходный index.html не предназначен для запуска двойным щелчком: TypeScript обрабатывает Vite.

## Как пользоваться

- «Новая запись» создаёт пустую запись и открывает её редактор.
- Название и текст изменяются сразу, отдельное сохранение не требуется.
- Кнопки меню слева переключают записи. Без заголовка показывается «Без названия».
- Поиск проверяет заголовки и текст без учёта регистра. Он фильтрует меню, а открытая запись остаётся доступной в редакторе. Очистите запрос, чтобы вернуть весь список.
- Удаление требует подтверждения. После удаления выбирается первая оставшаяся запись.
- При первом запуске есть пример. Если удалить всё, после перезагрузки список останется пустым.

Данные сохраняются только в текущем браузере для текущего адреса сайта. Очистка данных браузера удаляет записи. Сервер и синхронизация не используются. При ошибке localStorage появляется предупреждение.

## Структура и код

```text
src/
  components/
    NotesSidebar.tsx  — создание, поиск и меню записей
    NoteEditor.tsx    — заголовок, textarea, удаление, счётчики
  hooks/
    useNotes.ts       — состояние, операции и localStorage
  App.tsx             — главный экран, фильтрация, выбранная запись
  main.tsx            — точка входа React
  styles.ts           — общие стили Emotion и форматирование даты
  types.ts            — интерфейс Note
```

`Note` описывает id, title, body и updatedAt. `useState` хранит массив и выбранный идентификатор. `useEffect` записывает изменения в localStorage. Данные из хранилища проверяются во время выполнения. `map` обновляет запись без мутации, `filter` удаляет и фильтрует записи. Поля управляемые: их value берётся из состояния, onChange обновляет состояние. Emotion создаёт стилизованные компоненты; активная запись получает отдельный фон.

## Проверка вручную

1. Создайте две записи с разными заголовками и текстом.
2. Переключитесь между ними: убедитесь, что тексты независимы.
3. Измените текст, обновите страницу и проверьте сохранение.
4. Найдите запись по заголовку и фрагменту текста; проверьте другой регистр и отсутствие совпадений.
5. Отмените удаление, затем подтвердите его.
6. Удалите все записи и обновите страницу; создайте запись из пустого состояния.
7. Проверьте узкое окно и работу с клавиатурой.

## Статус проверки

Сборка в среде подготовки не проверена: npm install остановился с ошибкой TLS ERR_SSL_PACKET_LENGTH_TOO_LONG при подключении к registry.npmjs.org. После установки зависимостей выполните npm run build и пройдите список проверок выше.
